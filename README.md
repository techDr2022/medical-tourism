# Medical Tours India — Joint Replacement Google Ads Landing Page

## Stack
- Next.js App Router
- React
- Plain CSS (no UI framework required)

## Run
```bash
npm install
npm run dev
```

Open http://localhost:3000

## Before production
1. Replace `public/joint-replacement-ad.png` with your approved hero image if required.
2. Connect the form to your CRM/email/API.
3. Replace the placeholder WhatsApp link with your official WhatsApp number.
4. Add your Google Ads `gtag` snippet in `app/layout.tsx` or a dedicated analytics component.
5. Replace `track()` with your Google Ads conversion event ID/label.
6. Confirm package prices, inclusions, hospital stay and "First 50 patients only" offer before publishing.
7. Add privacy policy, terms, consent wording and any required medical advertising disclosures.
